## How I solve a problem

1. Read the problem and write down my own example before touching code.
2. Try a brute-force idea first, and note its complexity.
3. Look for the pattern that makes it faster (hash map, two pointers, sorting, and so on).
4. Code it, run my own edge cases (empty input, one element, duplicates), then submit.
5. Write the approach and complexity in my own words in the file header.
6. If I had to look at a hint or a solution, I say so in the file and solve the problem again a few days later from memory.
